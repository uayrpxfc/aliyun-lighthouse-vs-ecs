## 轻量应用服务器的隐藏限制，下单前看一眼

轻量为了简化体验设了几条硬性限制，参数页里不太显眼，但会影响实际使用，主要包括：

- 公网IP不支持更换，服务器到期后IP也不会保留。业务需要固定IP长期使用的话，这点要提前考虑。

- 系统盘采用本地磁盘，不具备云盘那样的数据自动冗余能力，重要数据要自己做好备份。
- 数据盘只支持挂载一块，而且只能在创建服务器时挂载，下单前就要想好。
- 不支持配置IPv6，也不支持部署集、资源编排、弹性伸缩、标签、资源组这些ECS的高级功能。
- 不能安装虚拟化软件做二次虚拟化，也不支持声卡应用。

**轻量应用服务器和ECS能内网互通吗？**

**轻量应用服务器能跑深度学习吗？**

不能胜任。深度学习、科学计算需要ECS的GPU实例，轻量的固定套餐没有这类硬件。

**轻量应用服务器以后能升配置吗？**

能升级到更高的套餐，也能整体迁移到ECS，但不支持像ECS那样对CPU、内存随时单独升降配。确定业务会快速增长的话，直接用ECS更省事。

**网站要用的端口怎么开？**

默认只有22和3389是开的。80、443要在轻量的防火墙或ECS的安全组里手动放行，数据库3306端口同理，用不到的建议保持关闭。
